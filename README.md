# 火力冲门 / Gate Rush

最新版：`0.4`，源码备份日期 2026-11-10。
安装包、校验值及交付说明见 [0.4 Release](https://github.com/hyd1059320441-bot/gate-rush-demo/releases/tag/v0.4)；
恢复构建与源码清单见 [备份说明](github-backup/README.md)。

PICO B3110 上的第三人称自动跑动射击小游戏。蓝色小人自动向前跑并持续开火，玩家选中小人后左右拖动；松手保留横向位置。

## 玩法

- 点击「开始挑战」，选中蓝色小人并向左右拖动，选择要击破的门或敌人。
- 门上的数字是剩余耐久。打碎门立即获得其标注的道具，绕过未打碎的门不会获得奖励。
- 攻速、护盾等所有奖励箱显示 40 点耐久，可射击打碎立即获得；未打碎的箱子仍可沿所在路线经过拾取，同一个箱子只奖励一次。
- 散射增加弹道，穿透连续命中不同目标，爆炸弹伤害附近目标，攻速增加自动开火频率，护盾抵挡一次碰撞，回血恢复最多 25 点生命。
- 冰冻弹将敌人移速降至 60% / 40%，持续 1.4 / 2 秒；电弧弹跳击最近的 1 / 2 个敌人；燃烧弹每 0.4 秒追加 2 / 3 点伤害，持续 2 秒。三种弹药各可叠两层，可同时组合散射、穿透和爆炸。
- 五关各约 60 秒，每关重新计算生命与道具。击破终点目标并活到计时结束才能过关。
- Boss 的红色路线预警出现后，拖动小人离开该路线。暂停保留位置、生命、道具和进度；重开重置当前关卡。

## 本版包含

独立左右髋关节摆腿、身体起伏与前倾、启动时前进 3.5 厘米、枪械后坐力、枪口闪光、受击侧倾和死亡倒下。路面标线、路灯、中景设施和远景小建筑有不同推进速度。门碎片、敌人碎片、爆炸环、回血脉冲和护盾抵挡使用有数量上限的对象池。

七类模型通过 Editor MCP 生成。上半身和单腿使用图片引导生成，实际六视图检查后才接入。原始 USDZ 保留在 `editor-asset/`，运行副本保持原始几何并将纹理压至 1024 像素以内；哈希和处理说明在 `.scratch/runtime-asset-provenance.json`。

0.2 新增全天球浅蓝天空和柔和云层、低饱和地面、圆润远山与两侧花园，使用完整虚拟环境模式。九种柔和音效覆盖射击、命中、破门、敌人消散、爆炸、拾取、护盾、受伤与通关；声音削弱高频并控制增益、限流和叠加。暂停、进入后台或 Stage 失焦立即停声；PICO Home 菜单出现时也会暂停，返回后手动继续，继续游戏不会重放暂停前的声音。

0.3 将小人统一缩至 70%（约 16.5 厘米高），门、敌人和箱子分别放大至原来的 1.15、1.75、1.5 倍。弹道与命中碎屑降至 11.2 厘米，枪口、模型边界、子弹宽度及前表面碰撞使用同一套尺寸规则。敌人每四秒以两列或三列编队出现，五关分别有 26、26、25、36、33 个敌人（含终点目标）；普通增援有 32–64 点生命，14 个敌人显示槽能覆盖不击杀情况下的最大并发。箱子可打碎或经过拾取，支持穿透与爆炸，射击和接触同帧仍只发一次奖励。

0.4 新增冰冻、电弧、燃烧三种弹药补给。基础弹、穿透弹、爆炸弹、冰冻弹、电弧弹和燃烧弹有不同颜色、核心形状与拖尾；组合时保留电弧色拖尾和冰色弹环，枪身显示对应弹药芯。敌人减速时出现冰环，燃烧时出现暖色火焰，电弧以折线连接实际受击敌人。敌人显示槽扩至 28 个，覆盖全程 40% 移速的保守并发上限；电弧使用 24 个显示槽。新表现复用场景网格、材质和对象池。

0.4 同时替换射击、命中和敌人消散的 WAV，采用无噪声的中频能量音，移除原来的低频下滑敲击感；16 ms 渐入、50 ms 渐出，播放增益分别降至 0.15、0.11、0.22。新素材峰值为 0.34–0.48，200 Hz 以下及 3 kHz 以上能量占比均低于 0.00001%。音效限流、叠加余量和暂停/失焦立即静音保持生效；主观听感由佩戴设备确认。

## 工程与交付

- 包名：`com.example.gaterush.p7c91a3e2`
- Spatial SDK：`6.3.2-rc.1`
- 安装包：`deliverables/GateRush-0.4.apk`（保留 0.1、0.2、0.3）
- 设计依据：`.scratch/design-spec.json`，修订 15；共享战斗尺寸见 `domain/model/CombatGeometry.kt` 和 `GameModel.kt` 中的 `ShotType`
- 玩法规则：`domain/usecase/PlayGameUseCase.kt`
- 场景与动画：`scene/GateRushScene.kt`
- UI：`ui/game/`，使用原生 SpatialUI 和 PicoTheme

JDK 21、Android SDK 35 环境下执行：

```sh
./gradlew --no-daemon assembleDebug testDebugUnitTest
pico-cli app install deliverables/GateRush-0.4.apk --replace --device PB331XPGL6040019G
pico-cli app launch com.example.gaterush.p7c91a3e2 --activity .platform.LaunchActivity --device PB331XPGL6040019G
```
