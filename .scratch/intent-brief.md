# 火力冲门 · 已确认功能

## Original intent
肯定要有道具的，而且我不是手动射击，你得设计个小人自己打，不过我可以选中小人拖动它左右移动，门被打破，敌人被打死都得有特效，而且有好几个关卡。按你说的所以开始吧，我要你完美复刻这个小游戏，需要的模型一样通过 editor 的 MCP 去生成。你要小人前进，动画不能少，衬托它前进的物体不能少，美术风格得统一啊。

## Product goal
在 PICO 上实现规则简单、动作反馈强的第三人称数字门射击小游戏。
小人自动前进与射击，玩家通过左右拖动做出路线、奖励和躲避选择。

## Requested core capabilities
- 选中小人并左右拖动，松手保留位置；前进与开火由游戏自动执行。
- 可射击的数字门、敌人、道具，以及多个关卡。
- 门击破与敌人死亡有明确可见的特效。
- 主角跑动、开火、受击和死亡有动画；环境物体明确衬托前进。
- 角色、环境、道具、门和特效保持统一美术风格。
- 所需模型通过 Spatial Editor MCP 生成。

## Accepted conversation context
用户以“按你说的”接受此前补充：五个关卡，散射、穿透、爆炸弹、攻速、护盾和回血，
道具自动拾取并可组合，武器升级可见，障碍与近身敌人造成伤害，失败可快速重试。
关卡节奏从操作教学、路线取舍、障碍快敌、装甲突破到机械 Boss。

## End-to-end flow
开始关卡 → 主角自动跑动开火 → 玩家左右拖动射门、拾取与避障 →
击破奖励并增强火力 → 清理敌群和终点目标 → 结算后继续下一关或失败重试。
